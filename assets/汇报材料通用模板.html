使用说明（导出前点工具条「隐藏说明」；打印 / 导出 PNG 时会自动去掉）

1. 点「开启编辑」后所有虚线框文字可直接改，改完「保存 HTML」覆盖本文件（⌘S）。
2. 页序：封面 → 目录 → 01 业务总览 → 02 项目进展（每个项目 2 页）→ 03 未来规划。项目不够就整块复制一对 <div class="page">…</div>；多余的直接删掉整块。
3. 每个项目固定 7 段：现状洞察 / 产品方案 / 项目卡点 / 寻找的解法 / 数据效果 / 后续想法 / 一句话方法论。别写成功能清单。
4. 漏斗条：改 width:__% 和数字即可，宽度按相对值填。
5. 图位（虚线框）里把 <span>…</span> 换成 <img src="路径">；也可以点一下要放图的虚线框，再按 ⌘V 粘贴截图（原图不压缩）。
6. 数据下面一定写口径（时间范围 / 单位 / 是否过滤），否则会被追问。
