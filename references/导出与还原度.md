# 导出与还原度（PDF / PPT）

> 正文见 SKILL.md。这份是**动手改导出逻辑 / 查还原度**时才需要读的细节。

### ⭐ 一键直出 PDF（零弹窗，2026-09-27 落地并实测通过）

用户明确要"点了就直接下载、别弹配置框"。`window.print()` 必然弹打印对话框，所以走**位图路线**：

1. **内联 html2canvas 1.4.1**（`libs/html2canvas.min.js`，198KB）。中文无需嵌字体——由浏览器渲染，所见即所得。
2. **导出前预处理** `exportPrep()`：关左栏 → 退出编辑态 → 藏 `.topbar` / `.help` → `wrap.style.zoom=1` → `body.classList.add('capturing')`（CSS：`body.capturing .page{border:none;border-radius:0}`，否则 PDF 四角带圆角描边）。导出后 `exportRestore(st)` 原样还原。
3. **`inlineImages()`**：抓图前把相对路径 `<img>` 经 canvas 转 data URI（**PNG 无损**），否则 file:// 下本地图会被安全策略挡成白框；结束后还原 `src`。
4. **逐页抓图**：`await html2canvas(pageEl,{scale:3,backgroundColor:'#ffffff',useCORS:true,logging:false,windowWidth:Math.max(innerWidth,1124),windowHeight:Math.max(innerHeight,scrollHeight)})` → `toDataURL('image/jpeg',0.94)`。**必须传 windowWidth**，否则窗口窄时克隆体布局会崩。
5. **手写最小 PDF** `pdfFromJpegs()`：每页一个 `/XObject /Subtype /Image /Filter /DCTDecode`，JPEG 字节**直接嵌入不再二次压缩**；页对象 `/MediaBox [0 0 720 540]` = 10in×7.5in 横向 4:3；内容流 `q 720 0 0 540 0 0 cm /Im0 Do Q`。
   - 对象编号：1 Catalog、2 Pages，第 i 页用 `3+3i / 4+3i / 5+3i`（Page / Contents / Image）。
   - 关键实现：`emit(num,dict,stream)` 累加 `pos` 记 xref 偏移；`strBytes(s)` 用 `charCodeAt(i)&0xff` 转字节；JPEG 从 dataURL 用 `atob()` 取二进制（**别用 base64 字符串直接进 Blob**）。
   - 8 页实测 **4.14MB / 约 2 秒**；xref 偏移全部正确，Chrome/Safari/预览均可打开。
6. **失败兜底**：`catch` → `showModal` 提示并提供「改用打印」；`finally` 里务必 `restoreImages` + 移除 `capturing` + `exportRestore` + 释放 `_busyPDF`。

**验证方法（可复用）**：`Chrome --headless=new --remote-debugging-port` + 原生 `fetch`/`WebSocket` 驱动 CDP（Node 22 自带，无需 puppeteer）：`Browser.setDownloadBehavior{behavior:'allow',downloadPath}` → `Runtime.evaluate('downloadPDF()')` → 轮询下载目录；再按 `/DCTDecode` 后的 `/Length` 抽出内嵌 JPEG 逐页看图核对。
⚠️ 抽图时 `/Length` 要取 **`/DCTDecode` 之后**那个（之前的是内容流的 8 字节），否则只导出 8 字节。

### ⭐ PPT 可编辑版的两个致命坑

1. **阈值必须在 px 层面判断**：`if(q.w>=2 && q.h>=2)` 里的 q 是**英寸**——2 英寸 ≈ 135px，会把卡片标题（13px ≈ 0.19in）和所有正文**全部跳过**（实测只生成 10 个对象）。正确做法：`ok(r){return r.w>=2&&r.h>=2}` 判断原始 px，英寸只用于最终坐标。
2. **删依赖要同步改检测**：移除 html2canvas 后若 `downloadPPT` 里仍检测 `typeof html2canvas==='undefined'`，会永远弹"缺少导出库"。**增删依赖时同步改所有检测条件与提示文案。**

### ⭐ DOM → PPT 转换：五个"写死值"陷阱（都会导致排版与 HTML 不一致）

| 项 | ❌ 错误做法 | ✅ 正确做法 |
|---|---|---|
| **行高** | ① `lineSpacingMultiple:1.1` 写死；② 用 `lineSpacingMultiple = lineHeight/fontSize` | `lineSpacing = 行高px * SX * 72`（**磅值**，见下「行距」专条）。⚠️ **别用 `lineSpacingMultiple`** |
| **圆角** | `rectRadius:0.05` 写死 | PptxGenJS 的 `rectRadius` 单位是**英寸**：`RAD(el) = borderTopLeftRadius * SX`（卡片 10px ≈ 0.096in） |
| **内边距** | 忽略 `padding-left` | 列表项 `.ul div{padding-left:11px}` → `x += pl*SX`、`w -= (pl+pr)*SX` |
| **列表圆点** | 不画 | HTML 用 `:before` 画的圆点 PPT 里没有 → 文字前加 `• ` |
| **页级元素** | 只扫 `.blk` 内部 | `.concl`（结论条）是**页级**的，必须 `page.querySelectorAll('.concl')` 单独处理；它是蓝底 + 白字，**不画底色白字就看不见** |

另：`txtOf` 提取行内小胶囊 `.chip-n` 时要补顿号，否则会粘成「能力 1能力 2」。

### ⭐ 再补三个「看起来像 bug」的坑

| 症状 | 根因 | 修法 |
|---|---|---|
| **某页缺序号** | 该页 HTML 里本身就没有 `.pnum`（如目录页），不是转换问题 | 补 `.pnum` 元素；不属于章节体系的页用 `—` 占位 |
| **标题在 PPT 里折成 2 行** | 标题框宽 = **文字宽度**（实测只有 295px，可用 943px）；PPT 与浏览器的字体度量略有差异就折行 | **标题 / 卡片标题的框宽要扩展到容器右边距**，不能用元素自身的文字宽度 |
| **行内加粗丢失** | 按整段 `font-weight` 判断，`<b>` 标签里的加粗全丢（实测 30 处） | 用 `richOf(el)` 生成 runs：`<b>/<strong>/font-weight:600` 标 `bold:true`，父级加粗作基线 |

**剩余固有限制**：PPT 与浏览器的文本换行算法不同（长文本换行位置会有差异）；行内小胶囊在 PPT 里只能是"文字+顿号"，画成独立框会和父文本重复。

### ⭐ 行距：必须用磅值 `lineSpacing`，不能用 `lineSpacingMultiple`

```
CSS:  line box = line-height × font-size        （.bd 15.5px × 1.65 = 25.6px）
PPT:  spcPct   = 百分比  × 字体自然行高(≈1.4em)   （1.65 → 1.65×1.4×15.5 = 35.8px）
```
同一个 1.65 到 PPT 里多出 ~10px/行，**首行被整体往下压**（实测正文下移 **8.5px**），于是「原方案」被下面的图位框压住。改成磅值后偏差降到 **3px**：
```js
function LHPT(el){ var lh=parseFloat(getComputedStyle(el).lineHeight);
  return (isNaN(lh)||lh<=0)?undefined:Math.max(6,+(lh*SX*72).toFixed(1)); }   // 传 lineSpacing:LHPT(el)
```
安全性：本项目 CSS 行高都 ≥1.55em，而字体自然行高约 1.4em，所以磅值行距 ≥ 自然行高，**不会被 PowerPoint 裁字**。

### ⭐ z 序：所有"底/框"必须先画，文字后画（否则形状盖住文字）

只有一条规则：**同一个块里，先画完所有形状，再画所有文字**。踩过的两个坑都出自这条：
- 图位形状在文字之后画 → 蓝底虚线框把「原方案：____」压掉一半；
- `.kpi` 卡面在正文之后画 → 卡片里的「指标名 / X→Y / ↑+__%」被白底完全盖住（表现为"指标卡是空的"）。

正确分两遍：
```
Pass A 背景层：卡片矩形 → .ib/.ti 小卡 → .ih i 圆点 → .kpi 卡面 → 图位（有图 addImage / 无图画虚线框）
Pass B 文字层：标题(.bt/.tname/.tnum) → 正文(.bd/.ul div/.tlist div/.tc/.ih/.ic/.k/.v/.d) → 图位文字
Pass C 组件：表格 → 漏斗(.fgh/.fbar/.fbar i/.fl/.fv)
Pass D 页级：.concl → 箭头 → 胶囊标签（最后画，保证压住卡片与表格）
```

### ⭐ PPT 还原度全量核对清单（照着过一遍就不会漏）

**结构性选择器，每个都必须有对应处理**（漏一个就是一整类模块在 PPT 里消失）：

| 结构 | 处理 | 备注 |
|---|---|---|
| `.pnum` / `h2` / `.sub` | 页眉文字 | `.sub` 最容易漏（选择器常只写 `.pnum,h2`） |
| `.pf` 页码 | 文字（右对齐） | **框宽要向左扩 160px**：它本来就贴右边距，向右扩等于没扩 |
| `.blk` / `.tcard` | 卡片矩形 + 标题 | 标题找 `.bt \|\| .tname` |
| `.tnum` | 目录页 01/02/03 | **大号斜体**：`italic:true`，不要漏（漏了目录页整排号码消失） |
| `.tag` / `.st` / `.tp` | 胶囊标签 | ⚠️ 这三类**恰恰会被 `txtOf/richOf` 从正文里 removeChild 掉**（防重复），所以**必须单独补画**圆角矩形+边框+居中文字；表格里的 `.st`（已建设/待建设）也靠这层画，否则状态列全空 |
| `.ib` / `.ti` | 白底圆角小卡 | 它们不是 `.blk`，没有任何选择器会命中 |
| `.ih` / `.ic` | 小标题 + 说明 | 同样不在正文白名单里，要手动加 |
| `.k` / `.v` / `.d` | 指标卡三段 | **逐个按自身 rect 定位**，别塞进一个居中文框（内容高过卡面会上下溢出、压住上一行） |
| `.phimg` / `.ibimg` | 图位 | 颜色取 computed style，别写死蓝色（橙卡里的图位是橙的） |
| `table` | `addTable` | ⚠️ **必须传 `colW`（首行 `th` 宽）+ `rowH`（每 `tr` 高）**，否则字体一变行就被撑高，下面所有形状都错位 |
| `.fgh` / `.fl` / `.fbar i` / `.fv` | 漏斗 | 别忘了 `.fbar` **底槽**（浅色轨道），只画橙色条会像悬空色块 |
| `.concl` | 页级实底+白字 | 页级元素，不在 `.blk` 里 |
| `.arw-d i` / `.arw-r i` | 灰色箭头 | 0×0 + border 三角形 → `ShapeType.triangle` + `rotate`（下 180 / 右 90） |

另：封面这类"无卡片页"要单独兜底（按 `[data-edit]` 生成），否则整页空白。

### ⭐ 怎么查还原度（不要靠猜，用这三步）

1. **导 PPTX + dump DOM**：headless Chrome + CDP（Node 22 自带 `fetch`/`WebSocket`，不用 puppeteer）执行 `downloadPPT()` 落盘，同时 `Runtime.evaluate` 把每页所有叶节点的 `{text,x,y,w,h,fs,class}` dump 成 JSON。
2. **文本差集 = 回归指标**：`unzip` pptx → 解析 `ppt/slides/slideN.xml` 的 `<a:t>`，与 DOM 叶文本逐个比对（记得先把 `&quot;` 等实体还原）。修复前 55 处缺失 → 修复后 0，这个数字比看图可靠。
3. **几何比对**：slide XML 里 `<a:off>/<a:ext>` 是 EMU，换算回页面 px：`EMU / 914400 / (10/1044)`，直接和 DOM 的 rect 对齐；要看到画面就用 `soffice --headless --convert-to pdf` + `pdftoppm -r 150 -png` 逐页渲染。
   ⚠️ LibreOffice 没有腾讯体 → 字形更宽，会出现"多折一行"的假问题，**别照着它改版式**，只用来核对位置与缺失。

### ⚠️ 改这个模板前必看

- **`s.replace(a,b,1)` 会打歪**：曾用它替换"文件末尾的初始化"，结果命中废弃函数体内的同名字符串，把 `initLayout()` 插进了 `toggleDrawer`，初始化根本没执行。→ **做"应当全局唯一"的替换前，先 `count()` 确认出现次数，或用足够长的上下文锚定。**
- 工具条在窄中间区会溢出被压掉 → `flex-wrap:wrap` + 按钮 padding/字号压缩到 12px / 10px。
- `zoom` 在 Firefox 126+ 才支持；本环境（Chrome/Safari/内置浏览器）没问题，要兼容 Firefox 需换 `transform:scale` + 高度补偿。
- `serializePage()` 依赖 `.blk / .tcard / [data-edit]` 三类节点（版本快照在用），改结构别破坏这三类。
- **面板从"抽屉"改成"常驻"时，初始化要跟着搬家**：右栏的 `loadPage()` 原本挂在 `toggleEditor()`（打开时触发），常显后没人触发 → **右栏永远空白**。凡把面板改成常显，必须把"打开时做的事"（加载数据 / 渲染列表）搬到 `initLayout()` 这类启动流程里。反向（**删面板**）同理：删掉入口后要顺手删掉它的启动调用，否则 `initLayout()` 会对着不存在的节点报错。
- **删掉面板会连带打断挂在它上面的功能**：图片粘贴原本靠右栏 textarea 的光标定位找目标图位。删面板后改成「**先点一下图位再 ⌘V**」：`mousedown` 记 `_lastPh`，`firstEmptyPh()` 兜底第一个空图位；并且**带 `text/plain` 的剪贴板直接放行**，避免抢掉往可编辑框里粘图文。→ 删 UI 前先搜一遍这个 UI 上挂了哪些事件监听。
- 图标字符别用生僻码位：`&#8249; &#8250;`（‹ ›）在腾讯体栈下会渲染成豆腐块，翻页按钮改用 `&lt; &gt;`。
- **PPT 必须显式指定字体**：`addText` 不传 `fontFace` 时 **PptxGenJS 默认写 Arial**，导出的 PPT 会和 HTML 完全两个样子。统一用 `PPT_FONT='腾讯体'` + 包装函数注入 `fontFace` 与 `margin:0`（默认内边距会把文字挤离原位）；表格 cell 的 options 也要补。⚠️ 腾讯体需本机安装，发给别人会回退。
- **动态浮层要排除在打印外**：`flash()` 提示用 `position:fixed`，`@media print` 必须把它一起 `display:none`（加专用 class），否则**提示文字会被打进 PDF**。downloadPDF 开头顺手清掉残留浮层。
- **批量替换函数调用会连函数自己的定义体一起换**：把 `sl.addText(` 全局换成 `AT(sl, ` 时，`AT()` 体内的 `return sl.addText(...)` 也被换掉 → **无限递归**。替换后先 `count()` 核对数量，再检查函数定义体。
